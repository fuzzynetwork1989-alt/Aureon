# Aureon

Aureon is a multi-platform cognitive operating system built from first principles.

## Scope
- Web client
- Desktop client
- Mobile client
- Shared runtime
- Persistent memory
- Safe autonomy
- Continuity across devices

## Development
- `pnpm install`
- `pnpm dev`
- `pnpm build`
- `pnpm lint`
- `pnpm typecheck`
